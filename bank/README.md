# CCArchPrep editorial samples

`sample-questions.json` contains ten original, structurally complete samples spanning all seven provisional PRD domains. They are **not live-bank questions yet**. The official exam guide has not been supplied, and no AI system can replace the two named human approvals required by the PRD.

Before changing an item to `approved`, reviewers must record:

1. the canonical blueprint version and learning objective;
2. independent confirmation that the item is original and not recalled exam/NDA material;
3. one-sentence defense of the best answer under the named constraint;
4. technical/factual verification and dated sources where applicable;
5. confirmation that each incorrect option has exactly one defensible mold label;
6. confirmation that the rationale addresses every incorrect option;
7. difficulty and accessibility review; and
8. two reviewer identities, decisions, and timestamps.

`ebook-remap.csv` is intentionally blocked rather than inventing chapter links. Replace each `TBD` only after the stable ebook edition and deep-link format are supplied.
