# Security policy

CCArchPrep is pre-release and has no public vulnerability bounty. Report suspected vulnerabilities privately to the project owner through the private GitHub repository's security-advisory feature. Do not open a public issue containing exploitation steps, credentials, user data, answer keys, or unreleased question content.

Include the affected component, reproduction steps, likely impact, and a safe contact method. The owner must define a monitored security email and response target before public launch.

Never commit credentials. If a secret is exposed, revoke and rotate it immediately, inspect access logs, preserve incident evidence, and remove it from all environments; deleting the Git line is not sufficient.
